# Habit Tracker: Màn Lịch sử và Design system (UI)

Phần giao diện do Trần Quang Khải phụ trách trong project nhóm **AppHabitBaKhiValorant**
(Android, Kotlin, XML, môn Mobile Application Programming).

Repo nhóm: https://github.com/dzpcrypt/AppHabitBaKhiValorant (đối chiếu lại link thật của nhóm)

## Nội dung

| Công việc | File |
|-----------|------|
| K2 – Design system trong Android | `res/values/themes.xml`, `colors.xml`, `dimens.xml`, `res/drawable/`, `docs/DESIGN_NOTES.md` |
| K3 – Màn hình Lịch sử | `res/layout/fragment_history.xml`, `res/layout/item_calendar_day.xml`, `res/values/strings.xml` |

Màn Lịch sử gồm chọn thói quen, lịch theo tháng, nút chuyển tháng và phân biệt
ngày hoàn thành / bỏ lỡ / chưa tới. Giai đoạn này dùng dữ liệu giả, chưa nối logic.

## Ghi chú về cách thực hiện

Phần XML được dựng với sự hỗ trợ của AI (Claude) dựa trên phân công của nhóm,
sau đó được xem lại và chỉnh sửa. (Bổ sung ở đây những chỗ bạn thực sự tự sửa.)

## Cách dùng

Chép các thư mục trong `res/` vào `app/src/main/res/` của project nhóm.
